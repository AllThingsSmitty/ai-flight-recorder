# AI Flight Recorder — Docs

Documentation site for [AI Flight Recorder](https://ai-flight-recorder.vercel.app), built with [Astro Starlight](https://starlight.astro.build).

## Development

```bash
pnpm install
pnpm dev      # starts at localhost:4321
pnpm build    # production build to ./dist/
pnpm preview  # preview the production build locally
```

## Deployment

The site is deployed to Vercel automatically on push to `main`.
